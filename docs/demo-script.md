# สคริปต์สาธิต liferpg (ประมาณ 10 นาที)

## เตรียมก่อนสาธิต (ทำล่วงหน้า 1 วัน)

- [ ] เปิด https://liferpg-five-zeta.vercel.app บนมือถือ แล้วกด "เพิ่มลงหน้าจอหลัก" (PWA)
- [ ] ติดตั้ง `mobile/liferpg.apk` บนมือถือ Android อีกเครื่อง (ถ้ามี)
- [ ] ล็อกอินบัญชีหลักไว้ล่วงหน้า บัญชีนี้มีด่านที่ผ่านแล้ว บอสที่ชนะ และพอร์ตโฟลิโอ `/u/leaf_adventurer`
- [ ] สร้างกิลด์ไว้ 1 กิลด์ ชวนเพื่อนเข้า 2–3 คน และให้แต่ละคนทำฝึกประจำวัน เพื่อให้อันดับ XP มีข้อมูล
- [ ] เตรียมไฟล์ส่งงานตัวอย่างใน `demo-submissions/` ไว้ในมือถือ (มีทั้งงานที่ผ่านและไม่ผ่าน)
- [ ] ลองส่งงานให้ AI ตรวจ 1 ครั้งในวันสาธิต เพื่อเช็กว่าโควตา Gemini ยังใช้ได้

## ลำดับการสาธิต

| นาที | สิ่งที่ทำ | ประเด็นที่พูด |
|---|---|---|
| 0–1 | เปิดหน้าแรกในโหมดไม่ระบุตัวตน | ปัญหาที่แอปแก้: ไม่รู้จะเริ่มสายไหน เรียนแล้วไม่ได้ลงมือ เลิกกลางทาง |
| 1–2 | กด "หาเส้นทางที่ใช่" ตอบ 4 ข้อ | แอปเลือก 3 จาก 43 เส้นทาง พร้อมเหตุผลและเวลาที่ใช้ |
| 2–3 | กด "ลองแบบ demo ก่อน" | เพิ่มเส้นทางให้อัตโนมัติ แล้วเปิดแผนที่ 8 ด่านทันที |
| 3–5 | สลับไปบัญชีจริง → เปิดเควสต์ → ติ๊กขั้นตอน → จับเวลาโฟกัส | ด่านมีขั้นตอนย่อยและเงื่อนไขสำเร็จที่ชัดเจน |
| 5–6 | ส่งงานให้อาจารย์ AI ตรวจ ส่งงานที่ "ไม่ผ่าน" ก่อน แล้วค่อยส่งงานที่ "ผ่าน" | AI ให้คำติชมและคำใบ้ ต้องผ่านจริงก่อนสู้บอส |
| 6–7 | สู้บอส ตอบคำถาม ใช้ไอเทม | เกม turn-based พร้อมเพลง เฉลยตรวจฝั่งเซิร์ฟเวอร์ |
| 7–8 | กดปุ่ม 💬 มุมขวาล่าง แล้วถามคำถาม | ผู้ช่วย AI ใช้ได้ทุกหน้า ไม่ต้องออกจากงานที่ทำอยู่ |
| 8–9 | เปิดพอร์ตโฟลิโอ และกดแชร์ | ผลงานที่ AI ตรวจแล้ว เอาไปแนบ resume ได้ |
| 9–10 | เปิดกิลด์และอันดับ XP รายสัปดาห์ | ใช้กับห้องเรียนได้ อาจารย์สร้างกิลด์แล้วให้นักศึกษาเข้าด้วยรหัส |

## ถ้าอาจารย์ถามเรื่องเทคนิค

- **ทำไมเป็นเว็บแอป + Android?** โค้ดชุดเดียวใช้ได้ทั้ง iOS (PWA), Android (APK ผ่าน Capacitor) และคอม อัปเดตครั้งเดียวทุกแพลตฟอร์มได้ทันที
- **กันโกง XP ยังไง?** เบราว์เซอร์ส่งแค่ "คำสั่ง" เช่น ทำเควสต์นี้เสร็จ ฐานข้อมูลตรวจเงื่อนไขและคำนวณรางวัลเอง จาก ledger ที่แก้ย้อนหลังไม่ได้
- **ข้อมูลผู้ใช้ปลอดภัยไหม?** เปิด Row Level Security ทุกตาราง และมีเทสต์อัตโนมัติยืนยันว่าผู้ใช้อ่าน/แก้ข้อมูลคนอื่นไม่ได้
- **ทดสอบยังไง?** มี 68 เทสต์ รวมเทสต์ที่รัน migration ทั้งหมดบน PostgreSQL จริง (`npm test`)

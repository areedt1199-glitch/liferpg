# คู่มือสาธิต liferpg MVP

## เปิดแอป
ใช้ Node.js 20.9+ และ environment ที่ตั้งไว้ในเครื่อง ห้ามใส่รหัสผ่านหรือ keys ในคู่มือ

```powershell
cd 'C:\งานอาจารย์นาราศักดิ์\liferpg'
npm ci
npm run build
npm start -- --hostname 127.0.0.1 --port 3010
```

เปิด http://127.0.0.1:3010/profile หาก server พอร์ตนี้เปิดอยู่แล้ว ให้ใช้หน้าที่เปิดอยู่ ไม่ต้องรันซ้ำ สำหรับพัฒนาใช้ `npm run dev -- --hostname 127.0.0.1 --port 3010`

## เลือกพื้นที่สาธิต
- **Demo:** หน้าโปรไฟล์ → เปิด demo ในเบราว์เซอร์ ข้อมูลอยู่ใน localStorage แยกจากบัญชี ไม่มีฐานข้อมูลรองรับ demo และต้องมี Web Locks บน localhost/HTTPS
- **บัญชี:** หน้าโปรไฟล์ → กลับโหมดบัญชีจริง → เข้าสู่ระบบด้วยบัญชีที่เจ้าของอนุญาต ใช้ความก้าวหน้าจาก Supabase อย่าใช้บัญชีส่วนตัวเพื่อสาธิตยืนยันผ่านงานที่ไม่ได้ทำ
- การกลับ demo ใช้ข้อมูลเดิม ไม่เริ่มใหม่และไม่มีปุ่ม reset ใช้ browser profile ใหม่ หรือพอร์ตที่ยังไม่เคยเปิดเมื่อต้องการ demo ว่าง เช่น `npm start -- --hostname 127.0.0.1 --port 3012` แล้วเปิด `/profile` และเลือก demo ไม่ต้องเปลี่ยน Auth redirect เพราะพอร์ตนี้ใช้ demo เท่านั้น
- LocalStorage แยกตาม origin/พอร์ต แต่ cookie เลือกโหมดใช้ host เดียวกัน หลังตรวจพอร์ตแยก ให้กลับโหมดบัญชีจริงก่อนใช้งานบัญชีตามปกติ

## ลำดับสาธิต
1. วันนี้ → เลือกเป้าหมาย “สร้างเกมแรก” → เปิดแผนที่ เห็นด่าน1พร้อมเริ่มและด่าน2–5ล็อก
2. แตะด่านล็อกเพื่ออ่านคำอธิบายได้ แต่เปิด focus ของด่านล็อกไม่ได้
3. เปิดรายละเอียดด่าน1 → เริ่มเควสต์ → โฟกัส มีงาน ขั้นตอนย่อย เงื่อนไขสำเร็จ และฉากคริสตัล
4. เริ่มรอบ → พัก → ทำต่อ ลองกลับรายละเอียด/รีเฟรช แล้วกลับโฟกัส สถานะยังอยู่ เวลาที่ running เดินต่อเมื่อออกหน้า
5. เช็กขั้นตอนตามงานตัวอย่างให้ครบ → ทำเควสต์สำเร็จ → อ่านเงื่อนไข → ยืนยันและรับรางวัล ไม่ต้องรอ timer ครบ
6. ด่าน1ได้120 XP/35เหรียญ เลเวล1→2 เปิดดูเควสต์ถัดไปเฉพาะรายละเอียด ต้องเริ่มเอง
7. ทำซ้ำครบ5ด่าน: เตรียมเครื่องมือ → ตัวแปรและเงื่อนไข → ฝึกลูป → เกมทายตัวเลข → ทดลองและปรับเกม
8. จบเส้นทางได้510 XP/150เหรียญ/เลเวล6 หน้าวันนี้แสดงจบเป้าหมาย แผนที่ผ่าน5/5และตัวละครอยู่ด่านสุดท้าย หน้าตัวละครยอดตรงกัน

## ข้อจำกัดก่อนสาธิต
ความสำเร็จเป็นการยืนยันด้วยตนเอง Checklist/timer ไม่พิสูจน์ว่างานเสร็จและไม่ผ่านอัตโนมัติ ไม่มีร้านค้า บอส Skill Tree หรือ3D

Demo ไม่ป้องกันผู้ใช้แก้ localStorage บัญชีใช้ RLS/transaction/ledger ฝั่งฐานข้อมูล แต่ยังขาด live verification สองบัญชีและอีก session เต็มชุด ไม่อ้างว่าการทดสอบ SQL ในเครื่องแทน Supabase Auth/Data API ได้

Supabase ส่งอีเมลมีข้อจำกัด หาก rate limited อย่ากดสมัครซ้ำ ใช้บัญชีที่ยืนยันแล้วสำหรับสาธิต การสมัครใหม่มีช่องยืนยันรหัสผ่านและต้องกดลิงก์ในอีเมลตาม configuration ปัจจุบัน

Account network request รอได้15วินาทีแล้วแจ้ง error ลองโหลดใหม่/ยืนยันซ้ำได้ อาจบันทึกสำเร็จที่serverก่อนresponseหาย ledgerป้องกันรางวัลซ้ำ ต้องรอการตอบรับก่อนรีเฟรชหลังแก้checklist

ดูผลตรวจและรายการที่ข้ามใน [verification.md](verification.md) และตั้งค่าบัญชีใน [supabase-setup.md](supabase-setup.md) ไม่ล้างข้อมูลหรือใช้ reset เพื่อเตรียมสาธิต

## สาธิตส่วนขยาย LifeQuest
เปิดเมนู เส้นทาง เพื่อเลือกแผนเรียน; ไป ร้านค้า ใช้เหรียญที่ได้จากเควสต์ซื้อชุดแล้วกดสวม; ไป กราฟ ดู XP/เหรียญที่ได้รับ/เควสต์จริง 7 หรือ30วัน; ไป ผู้ช่วย ลองถามตัวแปรกับ if/else
เส้นทางอื่นยังเป็นงานแนะนำ ไม่ใช่ด่านรับรางวัลใหม่ แชทฟรีเป็นค้นคลังบทเรียน ส่วน Gemini ยังไม่ตั้งค่าและไม่ใช้ระหว่างสาธิต ไม่ใส่ secrets ในคู่มือ
